# Design direction

Carry forward Anqi’s pastel portfolio and Access Studio: paper #fcf9fc, ink #34313e, lavender #e7ddef, blush #f1dfe8, mist #e1ece7, plum #725b83. Playfair Display provides the editorial voice; Inter keeps events and controls readable.

The main visual is an actual event trail beside a perforated delivery receipt. Multiple attempts accumulate on the left, while the right keeps one receipt: a visual explanation of idempotency.

Desktop: [workspace rail] [scenario chooser] [event trail | operation receipt]
Mobile: [navigation] [scenarios] [event trail] [receipt]

Motion follows active or delayed job states and stops for terminal states. Respect reduced-motion preferences. Do not use decorative counters, pretend logs, or progress inferred only from elapsed time. Before a visitor starts a run, show a clearly empty itinerary rather than fabricated activity.
